# Typing Tutor

Typing tutor is a typing learning and praticing application. It helps users learn typing, improve their typing speed and accuracy.

The application will provide two main setions:
1. Learning:
The learning section will guide users though keyboard layout and hand placement.
2. Practice:
This section will allow users to practice typing using different levels and typing modes.
